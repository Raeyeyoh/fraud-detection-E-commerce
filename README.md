Fraud Detection — Adey Innovations Inc.

End-to-end fraud detection system for e-commerce and bank credit card transactions,
built for Adey Innovations Inc. Covers data preprocessing, feature engineering,
model training, and SHAP-based explainability.

Business Context

Fraud detection is a high-stakes problem with two competing costs:

- False positives — legitimate transactions flagged as fraud, frustrating customers
- False negatives missed fraud, causing direct financial loss

This project builds models that balance both, evaluated on metrics suited for
imbalanced data
